# HBB Gene Analysis - Sickle Cell Mutation Detection

## Overview
Analyzed Human Hemoglobin Beta (HBB) gene (147 aa) to identify the mutation causing Sickle Cell Anemia.

## Tools Used
- Python, Biopython
- NCBI Database
- BLAST

## Key Results
- Verified 100% match with HBB protein
- Gene Length: 147 amino acids
- Mutation Found: Position 6, E (Glutamic Acid) -> V (Valine)
- Disease: Sickle-shaped RBCs cause blockage and pain
